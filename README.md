# Guías LED para Hyperion

Guías paso a paso para que Hyperion mueva las luces LED del monitor y de la tele.

Web: https://javisolven.github.io/guias-led/

- `hyperion.html`: tira DX Light (Robobloq) con Hyperion, con el paquete del puente (`hyperion-robobloq.zip`).
- `wled.html`: tira WLED con GLEDOPTO GL-C-616WL o SP803E.
- Las mismas guías en PDF.
